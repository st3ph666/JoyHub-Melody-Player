# JoyHub Melody Player v2.5.3

## Changes

- Updated public application version to v2.5.3
- Added bilingual Français / English interface
- Added in-app language selector
- Language selection is remembered in configuration
- Removed hard-coded personal media path
- Default video directory is now `~/Videos`
- Added `JOYHUB_VIDEO_DIR` environment override
- Removed dependency on a hard-coded private virtual environment
- Uses the Python interpreter that launches the application
- Declared `bleak` and `buttplug` dependencies

## Notes

This remains experimental community software. Test Bluetooth behavior with your own Melody hardware before relying on it for longer sessions.
